# 知命罗盘 · 前端部署文档

前端基于 uni-app（Vue 2），一套代码可发布到 **H5、微信小程序、App**。
本文档按平台分别说明。

> **前置条件**：请先完成后端部署并确认接口可访问
> （参见后端仓库 `docs/部署文档.md` 的「验证」一节）。

---

## 1. 通用配置（三个平台都要先做）

### 1.1 修改后端接口地址

打开 `api/config.js`：

```js
export let baseURL = 'https://api.your-domain.com/index.php/'   // 改成你的后端地址
```

要求：

- 必须是 **HTTPS**（微信小程序强制，H5 在 HTTPS 页面下也会被拦截混合内容）；
- 路径以 `/index.php/` 结尾，与后端 `public/` 目录对应；
- 后端已开启 CORS（后端 `public/index.php` 默认已支持）。

### 1.2 修改应用标识 `manifest.json`

| 字段 | 位置 | 说明 |
| --- | --- | --- |
| `appid` | 根节点 | 在 [DCloud 开发者中心](https://dev.dcloud.net.cn/) 申请后替换，否则无法云端打包 |
| `mp-weixin.appid` | `mp-weixin` 节点 | 替换成你自己的微信小程序 AppID |
| `h5.title` | `h5` 节点 | 浏览器标签页标题 |
| `name` | 根节点 | 应用名称 |

### 1.3 清理第三方统计代码（重要）

`template.h5.html` 中内置了原作者的统计与广告代码，**发布到你自己的站点前必须替换或删除**：

| 行 | 内容 | 处理 |
| --- | --- | --- |
| Google Analytics | `G-E71ME8X2M0` | 换成你的 ID，或整段删除 |
| 百度统计 | `hm.js?82cfa7d4938ffa071cf251aa1df94c6a` | 换成你的 ID，或整段删除 |
| Cookiebot | `data-cbid="20330d03-..."` | 不需要就删除 |
| Google AdSense | `ca-pub-1453367291536581` | 换成你的发布商 ID，或删除 |

> 保留原作者 ID 会把你自己站点的流量数据计入他人账号，且存在隐私合规风险。

### 1.4 替换图片资源（可选）

页面中的命理配图默认引用 `base2.tengsytech.com` / `csweb.tengsytech.com`。
自行部署时建议把资源下载到 `static/` 并改为相对路径，或换成自有 CDN，
避免依赖外部域名（小程序还需要在后台配置 downloadFile 合法域名）。

## 2. 开发环境准备

1. 下载 [HBuilderX](https://www.dcloud.io/hbuilderx.html) **App 开发版**
   （标准版不含 App 打包功能）。
2. `文件 → 导入 → 从本地目录导入`，选择本项目目录。
3. 首次运行会提示安装 `uni-app` 编译插件与 `scss/sass` 编译插件，确认安装。

## 3. 发布 H5

### 3.1 打包

HBuilderX：`发行 → 网站-H5手机版`（勾选「去除 console」以减小体积）。

> 若提示未安装 `scss/sass` 插件，按提示安装后重新打包。

产物目录：

```
unpackage/dist/build/h5/
```

### 3.2 上传

把 `unpackage/dist/build/h5/` 下的**全部内容**上传到你的 Web 服务器根目录，
例如 `/www/wwwroot/h5`。

### 3.3 服务器配置（关键）

`manifest.json` 中 H5 路由模式为 **`history`**，刷新子页面时服务器需要回退到
`index.html`，否则会出现 **404**。

#### Nginx

```nginx
server {
    listen 80;
    server_name h5.example.com;
    root /www/wwwroot/h5;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

#### Apache

在项目根目录放 `.htaccess`：

```apache
<IfModule mod_rewrite.c>
  RewriteEngine On
  RewriteBase /
  RewriteRule ^index\.html$ - [L]
  RewriteCond %{REQUEST_FILENAME} !-f
  RewriteCond %{REQUEST_FILENAME} !-d
  RewriteRule . /index.html [L]
</IfModule>
```

> **不想配置伪静态？** 把 `manifest.json` 的 `h5.router.mode` 改为 `"hash"`
> 即可，代价是 URL 中会出现 `#/`。

## 4. 发布微信小程序

### 4.1 打包

HBuilderX：`运行 → 运行到小程序模拟器 → 微信开发者工具`（调试）
或 `发行 → 小程序-微信`（生产）。

首次使用需要在「设置 → 运行配置」中填写微信开发者工具的安装路径。

### 4.2 微信公众平台配置

登录 [微信公众平台](https://mp.weixin.qq.com) → 开发 → 开发管理 → 开发设置 →
**服务器域名**，添加（必须是已备案的 HTTPS 域名）：

| 类型 | 填写内容 |
| --- | --- |
| request 合法域名 | `https://api.your-domain.com` |
| uploadFile 合法域名 | `https://api.your-domain.com` |
| downloadFile 合法域名 | 后端地址 + 图片 CDN 域名 |
| socket 合法域名 | `wss://api.your-domain.com`（仅在使用 IM 功能时） |

### 4.3 上传发布

微信开发者工具中点击「上传」，再到公众平台提交审核。

> 小程序上线需要先完成 **ICP 备案**，请提前准备。
> `manifest.json` 中已设置 `urlCheck: false`，开发阶段不会校验域名，
> 但**真机预览与正式版仍会校验**，务必在公众平台配好域名。

## 5. 发布 App（Android / iOS）

### 5.1 云端打包（推荐，无需本地环境）

HBuilderX：`发行 → 原生App-云打包`。

需要准备：

| 项 | 说明 |
| --- | --- |
| Android 包名 | 如 `com.yourcompany.zhiming`，上线后不可更改 |
| Android 证书 | 自有证书或勾选「使用 DCloud 公用证书」（公用证书仅便于测试） |
| iOS 证书 | p12 证书 + mobileprovision 描述文件（需 Apple 开发者账号） |
| 模块权限 | `manifest.json` 已声明相机、网络、振动等权限，按需增删 |

### 5.2 离线打包

如需接入自有原生工程或使用原生插件，参考 DCloud 官方离线打包文档，
把 `unpackage/resources` 下的资源导入 Android Studio / Xcode 工程。

> App 端同样需要 HTTPS 接口；若后端证书不受信任，Android 7+ 会出现网络失败。

## 6. 验证

| 平台 | 验证方式 |
| --- | --- |
| H5 | 浏览器打开站点，首页分类与 Banner 能加载即接口正常 |
| 微信小程序 | 开发者工具 Network 面板中请求返回 `code: 1` |
| App | 自定义基座运行后能正常加载首页数据 |

接口返回结构约定（见 `utils/request.js`）：

- `code: 1` 成功
- `code: 0` / `100` 失败，弹 Toast
- `code: 401` 未登录，跳转登录页

## 7. 常见问题排查

| 现象 | 原因 | 解决办法 |
| --- | --- | --- |
| H5 刷新子页面 404 | history 模式未配置伪静态 | 按 3.3 配置，或改为 hash 模式 |
| 页面白屏 | 接口地址错误或后端未部署 | 浏览器 F12 看 Network 请求地址与返回 |
| 请求提示跨域 | 后端 CORS 被 Nginx 覆盖 | 删除 Nginx 中额外的 CORS 头，交给 PHP 输出 |
| 小程序报错「不在以下合法域名列表」 | 公众平台未配域名，或用了 http | 配置 HTTPS 合法域名 |
| 开发者工具正常、真机请求失败 | 真机强制校验域名与 HTTPS | 同上，并确认证书有效 |
| 编译报 `scss` 相关错误 | 未安装 scss 编译插件 | HBuilderX 按提示安装 `scss/sass` 插件 |
| 编译报 `uview-ui` 找不到 | `uni_modules` 未完整导入 | 确认 `uni_modules/uview-ui` 目录存在 |
| 图片全部不显示 | 引用了外部 CDN 且小程序未配 downloadFile 域名 | 按 1.4 替换为自有资源 |
| 登录后立刻掉线 | 后端 JWT 密钥与前端不一致，或 token 过期 | 重新登录；确认后端 `.env` 的 `JWT.SECRET` |
| 支付调不起来 | 后端未配置支付参数，或 manifest 未勾选支付模块 | 在后端「系统 → 支付配置」填写商户信息 |
